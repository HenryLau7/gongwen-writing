# 公文写作 Skill

一个 [Claude Code](https://claude.com/claude-code) skill，帮助你将普通文本改写为符合中国党政机关公文规范的正式文本。

## 功能特性

- **多种输入方式**：支持纯文本、Word (.docx)、PDF 文件
- **智能文种推荐**：自动分析内容，建议最合适的公文文种
- **全面文种覆盖**：15种法定公文（通知、报告、请示、批复、函等）+ 事务性文书
- **规范套语内置**：开端用语、承启用语、结尾用语、表态用语速查
- **多种输出方式**：终端直接显示 或 导出为 Word 文档
- **合规红线保护**：禁止伪造公文、遵守新华社禁用词规范、敏感话题审慎处理

## 规范基础

- 《党政机关公文处理工作条例》（中办发〔2012〕14号）
- 《党政机关公文格式》（GB/T 9704-2012）

## 安装

### 方法一：通过 Claude Code 添加

```bash
claude /skills add /path/to/gongwen-writing
```

### 方法二：手动安装

将 `SKILL.md` 复制到你的 Claude Code skills 目录：

```bash
# 个人 skill 目录
cp SKILL.md ~/.claude/skills/gongwen-writing/SKILL.md
```

## 使用示例

安装后，在 Claude Code 中直接输入公文相关请求即可自动触发：

**改写普通文本：**
```
请把这段话改写为公文："我们部门最近搞了个新系统，想通知其他部门从下月起都用新系统。"
```

**指定文种撰写：**
```
帮我写一份请示，内容是向上级申请增加三个编制名额。
```

**读取文件改写：**
```
请读取 report.docx，将其改写为正式公文。
```

## 工作流程

```
输入文本或文件 → 分析内容 → 建议文种 → 用户确认 → 按规范改写 → 选择输出方式 → 附免责声明
```

Skill 会在关键节点暂停等待你的确认，不会自行跳过。

## 注意事项

- 所有输出均为 **AI辅助生成的参考草稿**，不具有法律效力
- 正式使用前请自行审核内容的准确性、合规性和适用性
- 本工具 **不会** 生成伪造的发文机关、发文字号或印章
